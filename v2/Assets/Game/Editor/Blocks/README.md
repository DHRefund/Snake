# Block editor tooling

Thư mục dành cho công cụ editor sắp triển khai:

- bake các layer `LegacyDefault` thành một sprite hoàn chỉnh cho từng mask;
- tạo/cập nhật `BlockSpriteSkin`;
- sinh contact sheet đủ 16 topology;
- validate naming, kích thước, pivot, PPU và số biến thể.

Mọi script tại đây phải nằm trong editor assembly và không đi vào player build.
